# Homestead

If you wish to use Homestead as a dependency in your projects, Homestead is available through our repository.


```xml
<repository>
    <id>magemonkey-snapshots</id>
    <url>https://repo.travja.dev/snapshots</url>
</repository>
...
<dependency>
    <groupId>studio.magemonkey</groupId>
    <artifactId>homestead</artifactId>
    <version>1.0.2-R0.3-SNAPSHOT</version>
</dependency>
```
